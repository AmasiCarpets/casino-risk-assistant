# Crash Fairness Lab

نسخة تعليمية لفهم Provably Fair.

## الوظائف
- حساب SHA-256 للبذرة المكشوفة ومقارنته بالالتزام السابق.
- توليد HMAC-SHA256 من Server Seed وClient Seed وNonce وRound.
- عرض أول 4 بايت وFloat تعليمي.
- إنشاء تسلسل Nonce وتصديره CSV.
- يعمل كتطبيق PWA على الآيفون وأندرويد.
