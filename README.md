# Limbo Demo

لعبة محاكاة أصلية مستوحاة من فكرة ألعاب Limbo، وتعمل بنقاط افتراضية فقط.

## التشغيل
1. فك الضغط.
2. افتح ملف `index.html` في المتصفح.
3. أو ارفع الملفات الثلاثة إلى GitHub Pages.

## الملفات
- `index.html`
- `style.css`
- `script.js`

لا تحتوي النسخة على إيداع، سحب، محافظ، أو أموال حقيقية.
