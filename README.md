# Casino Risk Assistant — نسخة تطبيق جوال

هذه النسخة PWA ويمكن تثبيتها على الشاشة الرئيسية مثل التطبيق.

## الرفع
ارفع جميع الملفات إلى مستودع GitHub Pages نفسه:
- index.html
- style.css
- script.js
- manifest.webmanifest
- sw.js
- icon-192.png
- icon-512.png

## التثبيت على الآيفون
1. افتح رابط الموقع في Safari.
2. اضغط زر المشاركة.
3. اختر "إضافة إلى الشاشة الرئيسية".
4. اضغط "إضافة".

## التثبيت على أندرويد
افتح الموقع في Chrome واضغط "تثبيت التطبيق" أو اختر "إضافة إلى الشاشة الرئيسية".

ملاحظة: يجب فتحه من رابط HTTPS مثل GitHub Pages حتى يعمل التثبيت والعمل بدون إنترنت.
