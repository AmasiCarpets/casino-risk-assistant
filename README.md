# Limbo Pro Demo

نسخة محسنة لمحاكاة لعبة Limbo باستخدام نقاط افتراضية فقط.

## المميزات
- رصيد افتراضي يبدأ من 1,000,000 نقطة
- Manual Bet
- Auto Bet
- اختيار سرعة اللعب
- سجل آخر 100 نتيجة
- إحصائيات الفوز والخسارة وصافي الربح
- تصميم متجاوب للجوال
- Hash لكل جولة لأغراض تعليمية
