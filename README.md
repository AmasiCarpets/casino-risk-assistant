# Crash Lab Pro

نسخة مطورة من التطبيق التعليمي.

## المزايا
- إضافة وتحليل نتائج الجولات السابقة.
- إحصاءات: المتوسط، الأعلى، الأقل، ونسب 2x و5x و10x.
- رسم بياني محلي بدون مكتبات خارجية.
- حفظ تلقائي في الجهاز.
- استيراد وتصدير JSON وCSV.
- التحقق من SHA-256 للبذرة المكشوفة.
- توليد HMAC-SHA256.
- Nonce Lab.
- يعمل كتطبيق PWA على الآيفون وأندرويد.

## التحديث
ارفع جميع الملفات الموجودة في هذا المجلد فوق الملفات الحالية في المستودع نفسه، ثم اضغط Commit changes.

التطبيق لا يتنبأ بالجولات القادمة ولا يعطي إشارات للمراهنة.
