# Limbo Multi — 10 Boards

نسخة محاكاة تحتوي على 10 لوحات مستقلة.

## طريقة العمل
- زر BET واحد يشغّل اللوحات العشر معاً.
- كل لوحة لها Client Seed وServer Seed وNonce وHash مستقل.
- مبلغ الرهان يطبق على كل لوحة.
- مثال: رهان 100 × عشر لوحات = تكلفة إجمالية 1,000 نقطة.

## التثبيت على GitHub Pages
استبدل الملفات القديمة:
- index.html
- style.css
- script.js
